# Ondrive

O Ondrive é um sistema web de gestão de frota criado para apoiar a operação administrativa de veículos, contratos, motoristas, financeiro e acompanhamento de alertas operacionais.

## Objetivo

Centralizar em um único sistema a gestão da frota, permitindo acompanhar veículos, contratos, pagamentos, documentos, aprovações de motoristas e rotinas operacionais de forma mais organizada.

## O que o sistema faz

O sistema possui dois ambientes principais:

### Área administrativa
Permite gerenciar a operação por meio dos módulos de:
- Início
- Dashboard
- Veículos
- Contratos
- Financeiro
- Alertas
- Sócios
- Aprovação de motoristas
- Chatbot Ondrive
- Configurações

Nessa área, o usuário consegue cadastrar veículos, criar contratos, acompanhar alertas, registrar lançamentos financeiros, aprovar motoristas e configurar regras básicas do sistema.

### Área do motorista
Permite acompanhar e executar ações operacionais, com as seções de:
- Meu painel
- Meu veículo
- Pagamento
- Agendar vistoria
- Meu contrato
- Meus documentos
- Informar KM
- Multas

Essa área foi pensada para facilitar a comunicação entre operação e motorista, concentrando as principais rotinas em um só lugar.

## Funcionalidades já previstas no sistema

- Login por perfil
- Navegação separada para administrador, sócio e motorista
- Cadastro e gestão de veículos
- Cadastro e gestão de contratos
- Controle financeiro com receitas, despesas e repasses
- Alertas operacionais
- Fluxo de aprovação de motoristas
- Upload de fotos, documentos e PDFs
- Área de multas
- Agendamento de vistoria
- Configurações de regras e mensagens
- Chatbot de apoio para consultas do sistema

## Chatbot Ondrive

O sistema inclui um chatbot interno para apoiar a operação, respondendo perguntas sobre:
- veículos e status
- contratos e atrasos
- financeiro
- alertas
- multas
- score e situação de motoristas

## Observação

Nesta fase, o sistema está estruturado como front-end funcional de demonstração e operação guiada. A próxima etapa consiste na conexão completa com banco de dados, autenticação real, armazenamento de arquivos e integrações externas.
